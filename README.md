# Used Car Price Exploratory Data Analysis (EDA)

## Project Overview

This project presents an Exploratory Data Analysis (EDA) of the Cardekho used car dataset. The objective is to understand the factors that influence used car selling prices through data cleaning, preprocessing, visualization, and statistical analysis.

This project was completed as part of my AI & Machine Learning learning journey at Najot Ta'lim.

---

## Objectives

- Explore the structure of the dataset
- Handle missing values and duplicate records
- Detect and remove outliers
- Visualize important relationships between variables
- Identify the factors that influence used car selling prices

---

## Dataset

The dataset contains information about used cars, including:

- Selling Price
- Manufacturing Year
- Fuel Type
- Transmission
- Engine Capacity
- Maximum Power
- Mileage
- Seller Type
- Ownership

## Key Findings

- Newer vehicles generally have higher selling prices.
- Cars with larger engines and greater maximum power tend to be more expensive.
- Selling price varies across different fuel and transmission types.
- The dataset contains a right-skewed selling price distribution due to a small number of high-value vehicles.
